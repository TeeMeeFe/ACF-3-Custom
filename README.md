# ACF-3-Custom

## What's this?
ACF-3-Custom, bringing features and the spirit of the [Old ACF-Custom](https://github.com/bouletmarc/ACF_CustomMod), meant to be more suitable for modern acf without giving up on the fun (and difficulty) of making your very own custom made acf contraptions. 

## Why?
Working within the main addon means two things for me:

1. We must follow their [CONTRIBUTING.md](https://github.com/ACF-Team/ACF-3/blob/master/CONTRIBUTING.md) guidelines. Easy, but the reason número **dos**... 
2. Code quality within the ACF-3 repo must be kept within reasonable levels, free of any effortless, 5 minute generated AI slop. **You must understand what the code means and does,** 
which is the contrary to what we're doing here.

I don't care if you think that everyone must have PhD levels of understanding of every feature/bug/change they want to see ported over. As long as you have a minimum level of programming and some common sense, we're good. 

***And finally. I made this repository to add a bunch of experimental features that don't inherently make sense to exist within the main addon.*** Features that for the most part, don't quite follow the developer's vision of the addon, which can end up being discarded entirely. 

## Features that this brings:
 * Scalable engines of any layout and size that you could possibly want and/or need.
 * Radiators, scalable, with three different configurations meant to tackle different temperature issues of real life engines.
 * Improved engine <-> gearbox simulation. Rev-matching, engine braking, multiple engines of varying size distributing their torque to one or more gearboxes, and more! 
 * And many more to come!

 ## Installing
Currently there's no workshop version of this addon just yet, so make sure to download this and drop it into your `addons/` folder within your Garry's Mod install. Or if you're a `Git` user, you can also clone this repository, ensure that your directory matches `addons/` folder at the very end of its path before cloning.
